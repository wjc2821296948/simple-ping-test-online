# simple-ping-test-online

一个简单的 Windows 局域网在线 IP 探测工具，通过系统自带的 `ping` 命令测试一个或多个网段中的 IP 是否在线。

## 功能

- 使用 Windows `ping` 检测主机连通性
- 支持对一个或多个网段进行在线 IP 探测
- 适合快速排查局域网设备是否在线
- 无需额外部署专用扫描服务

## 适用场景

- 查看局域网中当前在线的设备
- 批量检查一组 IP 地址是否可达
- 对多个网段进行简单的在线状态测试
- 在 Windows 环境中进行轻量级网络排查

## 工作原理

项目通过调用 Windows 提供的 `ping` 功能，向目标 IP 发送 ICMP Echo 请求，并根据返回结果判断目标主机是否在线。

需要注意的是，部分设备或防火墙可能会禁用 ICMP 响应，因此“Ping 不通”并不一定代表设备实际离线。

## 系统要求

- Windows
- 系统中的 `ping` 命令可正常使用
- 目标网络允许 ICMP 通信

## 项目状态

项目仍处于简单实现阶段，后续可继续完善扫描效率、结果展示、超时控制和异常处理等功能。
